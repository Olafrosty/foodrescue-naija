SECURITY FIRST: How we prevent kidnapping & scams

HUB-ONLY
1. No Home Pickups - BANNED

All food dropped at Dugbe Hub or partnered churches/mosques/markets. No private house address ever shown.

2. Phone Verification

Volunteer calls donor before listing goes live. No verification, no listing.

3. Daylight Only (8AM - 6PM)

Pickup time locked to daylight. System rejects night pickups. Crowded public places only.

4. Pickup Code: No code, no food

4-digit code auto-generated server-side. Receiver must show code at Hub.

5. Never Alone Rule

App forces safety modal: "Never go alone, share live location" + WhatsApp share button.

6. Report & Ban - 2 Reports = Hidden

Any listing can be reported. 2 reports = auto-hidden. 3 reports = phone blocked. Emergency: 199 / 112
